__When an element of the two-dimensional array board is accessed, the first index is used to
specify the row and the second index is used to specify the column.
Write the GameBoard method getPointsForRow. The method should return the point value
of the spaces in the row specified by the parameter targetRow. The point value of a row is
determined as follows.
• If not all spaces in the row are the same color, the point value for the row is the sum of
the points in the row.
• If all spaces in the row are the same color, the point value for the row is two times the
sum of the points in the row.__
